# Design
Install a per-user Chrome native messaging host restricted to the installed extension ID. Chrome launches the existing Node-based companion through a native host using a persistent connection. The extension obtains the ephemeral local pairing secret through that connection; OAuth tokens remain in companion memory. Keep existing loopback Host, Origin and pairing checks and OAuth callback validation. Terminate the helper on native-port disconnect; restarting requires sign-in again. Provide clear setup, disconnect and error states. Do not install a daemon or persist OAuth tokens. Initial target is macOS and the currently installed Chrome extension; do not change other Chrome installations. Preserve the existing manual setup until the new path is verified.
