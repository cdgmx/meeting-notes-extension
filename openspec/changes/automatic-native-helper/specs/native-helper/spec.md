## Requirements
### Requirement: Automatic local connection
After one-time installation, Chrome starts the authorized local helper without a terminal or manual pairing code. Only the specified extension can connect. Failures are visible and existing transcripts remain intact.
### Requirement: OAuth lifecycle
ChatGPT authorization continues through loopback and OAuth credentials remain only in helper memory. Disconnect stops the helper; restart requires sign-in.
### Requirement: Verification
Verify registration, native message framing, connection lifecycle, security boundaries and actual Chrome sign-in and notes flow. Independent security and quality review required.
