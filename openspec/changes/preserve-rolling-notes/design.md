# Design
Replace full-notes model response with append-only notesDelta. Existing notes remain byte-for-byte unchanged; delta can continue the final line or add new entries, and can be empty when no new information is present. Send prior transcript as contextSegments and unsummarized text as newSegments, with explicit instruction not to repeat prior material or rewrite existing notes. Keep existing deterministic transcript-correction validation and late-result matching. Before append require saved notes equal the request snapshot; fail explicitly without changing notes or progress if they differ. Persist appended notes and successful cursor atomically. Existing persisted notes remain untouched; no migration rewrites or cleared data. Semantic duplication can still occur with model output and must not be claimed impossible. Full original note text lost before this fix cannot be reconstructed reliably without a history.

## Approved context-aware correction
Track bounded topic, subjects and purpose context inferred only from recorded transcript; unknown facts remain unknown. Use context to disambiguate recent misheard words and batch boundaries, never to invent speech or rewrite old notes. Preserve original transcription. Only the latest five stored transcript segments may receive corrections at commit; older segments remain frozen even when notes lag. Context updates and successful notes progress persist together; Clear resets context with transcript. User explicitly approved this combined design with “aprove”.
