# Design
Capture shorter approximately five-second audio batches, subject to actual provider compatibility; this is batched transcription, not streaming. Use a bounded ordered transcription queue that stores each completed segment immediately, independent of a separate ordered notes worker. Coalesce pending note updates but track the last successfully summarized segment; include every newer segment in the next note request, splitting work if necessary so coalescing never skips context. Re-read current saved segments before applying validated corrections; update only matching original segments from the snapshot, preserving later transcript and prior edits. If matching cannot be established, skip corrections explicitly and keep valid notes. Serialize note updates and use the latest saved notes as context. Bound audio backlog and stop with explicit error if it cannot keep up; never silently discard queued audio. Stop flushes the final partial batch and drains transcription and final notes; surface failures and preserve already saved transcripts. Keep existing session, auth, capture access and helper contracts. Measure actual timing and disclose provider latency limitations; restore 15-second batches if live compatibility is not demonstrated.
