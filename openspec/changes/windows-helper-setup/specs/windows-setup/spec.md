## Requirements
### Requirement: One-time Windows helper setup
A user runs a guided installer once, supplies the installed extension ID and authorizes normal account sign-in. The helper is restricted to that extension and starts automatically through Chrome. Setup requires no admin and does not replace unrelated registrations or credentials.
### Requirement: Honest compatibility
Document explicit Chrome installation and capture invocation, regular-page support, unavailable Chrome internal/protected pages and tab-audio-only capture. Do not claim all-site or actual Windows verification without evidence.
