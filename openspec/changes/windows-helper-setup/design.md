# Approved scope
User requested automatic Windows setup and said “lets fix it” after the recommendation for a Windows installer bundling Node and prompting for extension ID. Implement that scope, retaining explicit Chrome Load unpacked and account authorization steps.

# Design
Add a double-click Windows setup entrypoint using built-in PowerShell. Prompt for this user's extension ID and validate exact format. Download a pinned official portable Node runtime from nodejs.org, verify pinned expected SHA256 before execution; use current-user storage and no admin, policy weakening or system runtime changes. Install required dependencies from lockfile. Register native host under HKCU Chrome NativeMessagingHosts with exact extension allowed origin; quote Windows paths/arguments safely and keep stdout reserved for native protocol. Refuse conflicting existing registrations, provide explicit failure and uninstall/recovery instructions. Preserve macOS path. No browser auto-install, microphone capture or universal site guarantee. Regular HTTPS tabs remain supported through explicit toolbar invocation. Test installer boundaries, register rollback, quoting and existing capture guidance; independently review security and quality. Actual Windows run requires Windows and remains incomplete if unavailable. Do not publish release binary or change repository visibility.
